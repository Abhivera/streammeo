# Track your request

## Open your link

Use the secure link from the company's email. No account or password needed.

If the link fails, it may have expired — email them again or start a new chat.

## On the page

- **Ticket number and subject** at the top
- **Status** — new, open, pending, resolved, or closed
- **Full conversation** — your messages and agent replies

## Reply

Type in the box at the bottom and click **Send reply**.

If the ticket was **resolved** but you still need help, send another message — it reopens automatically.

**Closed** tickets usually cannot be updated on the portal. Contact the company by email or chat instead.

## Status meanings

| Status | Meaning |
| ------ | ------- |
| New | Just received |
| Open | Agent is working on it |
| Pending | Waiting on you or a third party |
| Resolved | Team thinks it's fixed — reply if not |
| Closed | Finished |
