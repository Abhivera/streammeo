Welcome to our demo customer website

This page simulates a merchant site with the Streammeo live chat widget embedded. Click the chat bubble in the bottom-right corner to start a session — your support team can reply from Live chat in the agent console and convert the conversation to a ticket when needed.

Try the widget

  1. Copy your workspace API key from Settings → Workspace & billing (admin login).
  2. Open this page with ?apiKey=YOUR_KEY in the URL, or paste the key below.
  3. Click the chat bubble and send a message as a visitor would.
  4. Open Live chat in your agent console to see the session.
  5. Reply in real time, then use Convert to ticket if the visitor needs follow-up.
